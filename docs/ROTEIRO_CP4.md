# Roteiro do vídeo - CP4 individual

**Meta: 2 minutos. Faixa aceita: 1min30 a 2min30.** Grave com sua voz e o site publicado aberto em https://glameiras.github.io/portf-lio-cp3/. O vídeo deve mostrar o navegador, não apenas o editor ou slides.

## 0:00 a 0:15 | Página inicial

“Eu sou Gustavo Lameiras e este é meu portfólio individual, publicado no GitHub Pages. Ele apresenta minha trajetória e alguns exercícios de desenvolvimento web. Usei HTML para a estrutura, CSS para o visual e JavaScript para as interações.”

## 0:15 a 0:45 | Navegar pelas cinco páginas

Abra Currículo, Formulário, Multimídia e Gráficos pelo menu. Na multimídia, acione o som.

“O site tem cinco páginas: início, currículo, formulário, multimídia e gráficos. O formulário valida os campos, mas não envia mensagens. Na multimídia, tenho uma imagem SVG e um som gerado no navegador. Nos gráficos, usei SVG e canvas, com uma tabela que apresenta os mesmos dados.”

## 0:45 a 1:20 | Demonstrar JavaScript e persistência

Alterne o tema. Abra DevTools > Application > Local Storage e mostre a chave `portfolio-gustavo-tema`. Aperte F5 e navegue para outra página. Volte ao formulário, deixe os campos vazios e clique em Validar mensagem.

“A principal interação é a troca entre tema claro e escuro. O JavaScript salva a preferência no localStorage. Aqui aparece a chave com o valor escolhido. Vou recarregar: o tema continua igual e também permanece quando mudo de página. No formulário, a validação mostra o erro perto do campo e leva o foco ao primeiro problema.”

## 1:20 a 2:00 | Evolução e decisões

Volte ao início. Mostre os três cards; estreite a janela e use Tab para evidenciar o foco.

“A evolução até o CP4 passou pela estrutura das páginas, pelos estilos e pelas interações com persistência. Nesta versão final, integrei o grid do Bootstrap nos cards: row organiza a linha, e col-12 e col-md-4 adaptam as colunas à largura da tela. Mantive o CSS próprio para preservar o visual.

Também revisei contraste, descrição das imagens e navegação pelo teclado. Reforcei as bordas dos campos e permiti a quebra do código ilustrativo em telas pequenas. Usei assistência de IA na preparação do código e dos testes; revisei o funcionamento e estou estudando as decisões. A tag cp4-entrega identifica a versão final.”

## Antes de gravar

- Ensaie com cronômetro. As ações também consomem tempo; não leia os títulos ou as instruções.
- Abra o site sem login para conferir o acesso público e deixe as ferramentas do navegador preparadas.
- Use somente dados fictícios se preencher o formulário.
- A frase sobre revisão deve corresponder ao que você realmente fez: execute os testes manuais e entenda o código antes de gravar.
- Não é necessário mostrar seu rosto; o requisito informado é sua voz narrando o site em funcionamento.
- Se usar link de vídeo, deixe-o acessível ao professor e teste sem estar conectado à sua conta.
